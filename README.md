# psdavisbooks.com

**Author Portfolio Site for P. S. Davis**

This is the official website for P. S. Davis, built entirely from scratch using plain HTML, CSS, and JavaScript. The goal of the site is simple: create a private, elegant space to showcase original works without relying on ad networks, cookies, or tracking technologies.

---

## 📚 About the Site

This site serves as a digital home for my fantasy works, with a strong emphasis on reader experience, author authenticity, and data privacy.

- **All works are original and copyrighted.**
- There are **no ads**, **no trackers**, and **no cookies**.
- The design philosophy is minimal, fast-loading, and distraction-free.

Feel free to explore the site and its features. If you're interested in using the design approach, want to know more about the works listed, or need help adapting similar techniques for your own project, you're welcome to get in touch.

## 🛠️ Tech Stack

- **HTML** — clean semantic structure
- **CSS** — mobile-first responsive design with custom styling
- **JavaScript** — vanilla JS for modal navigation, carousel behavior, and interactivity
- **FontAwesome** — icon support
- **Google Fonts** — for readable, elegant typography

This site is intentionally kept **dependency-light** for speed and control.

---

## 🚀 Deployment

- **Hosting**: GitHub Pages  
- **Domain**: Managed via GoDaddy and pointed to GitHub infrastructure  
- **HTTPS enforced** for all access  
- Custom redirection from `www.` to `https://psdavisbooks.com`

---

## 🔐 Privacy Commitment

I do **not** use:

- Advertising platforms
- Analytics services (like Google Analytics)
- Third-party embeds
- Cookie-based trackers

This site reflects my belief that art and writing should be experienced without surveillance.
